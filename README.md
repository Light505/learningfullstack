# learningfullstack
Learning CI/CD with docker
STACK: Apache, MySQL, PHP

## Guides

- `LOCAL_DEVELOPMENT.md` - run the app locally, initialize MySQL, and publish
  images to GHCR from your machine.
- `DEPLOYMENT.md` - run the VPS stack with Traefik, HTTPS, Watchtower, and
  Docker-login based private GHCR access when needed.
- `COMPOSE.md` - explains the Compose file roles.
- `DEVELOPMENT_PLAN.md` - phased infrastructure roadmap.
