# Design Review Checklist

Use this before starting real mark submission. The goal is to approve the
frontend direction while the page is still easy to change.

## Overall Feel

- [ ] The page feels friendly and nostalgic.
- [ ] The cave-wall visual fits the `I was here` concept.
- [ ] The design feels like an app, not a marketing landing page.
- [ ] The canvas is the first thing the user notices.

## Canvas

- [ ] The canvas feels large enough to invite interaction.
- [ ] Sample marks are easy to notice without feeling noisy.
- [ ] Mark spacing feels organized and breathable.
- [ ] Selected, hover, and focus states are clear.
- [ ] The entry count is visible and understandable.

## Side Panel

- [ ] Selected mark details are easy to read.
- [ ] The compose preview makes the future workflow obvious.
- [ ] Disabled fields look intentional, not broken.
- [ ] Recent Marks feels compact and useful.

## Mobile

- [ ] The page is comfortable on phone width.
- [ ] Mark tap targets are large enough.
- [ ] The side panels stack in a sensible order.
- [ ] Text does not overflow or feel cramped.

## Copy

- [ ] The page title works: `I was here`.
- [ ] The canvas hint fits the mood.
- [ ] The empty state copy fits the mood.
- [ ] The prototype note makes it clear real submission comes later.

## Before Version 3

- [ ] Decide if the current color palette should stay.
- [ ] Decide if the cave-wall texture should stay.
- [ ] Decide if the mark shapes should stay.
- [ ] Decide if the side panel layout should stay.
- [ ] Decide whether to connect this exact design to real data.
